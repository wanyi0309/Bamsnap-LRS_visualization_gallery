Bamsnap-LRS · visualization gallery

Long-read alignment visualization comparison

Explore matched genomic regions across Bamsnap-LRS, Wally, and SVhawkeye. The gallery includes insertion, deletion, inversion, duplication, and RNA-splicing examples and preserves the original visualization output for each tool.

How to use. Select a variant class and locus to keep all three tools synchronized. Click an image to inspect its original resolution. Use ←/→ to move between loci. Deep links use ?type=INS&id=INS1, so individual examples can be cited or shared. A “Not available” card means no corresponding image was present in the uploaded result set.
Static, dependency-free gallery prepared for GitHub Pages.
